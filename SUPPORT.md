# Support

This repository is a community project and is not an official AgentScope or Tencent Cloud support channel.

## Ask for help

Open a GitHub Discussion or Issue with:

- SDK version;
- JDK vendor and version;
- AgentScope Java version;
- operating system or container image;
- Console or Cloud transport;
- sanitized error type and telemetry snapshot;
- minimal reproduction using synthetic content.

Never include SecretId, SecretKey, tokens, complete prompts, tool outputs, customer identifiers, Topic IDs, or private endpoints.

## Supported scope

The project supports:

- SDK integration questions;
- documented configuration;
- supported JDK and AgentScope combinations;
- reproducible bugs in the repository examples.

The project does not provide:

- Tencent Cloud account administration;
- CAM policy design for a specific organization;
- legal or compliance approval;
- model-provider support;
- production SLA;
- recovery of telemetry lost after process crashes or forced termination.
